[Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/c/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

Terrible advice delivered with total confidence: destroy production to test the backups, then shrug off the loss — deadpan, tight, worst advice an AI could give.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Delete production to test the backups. If the backups fail, you never needed that data anyway.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
